# 论坛树状创作与 Markdown 档案 · 2026-09-29

## 已确认需求

论坛是 Creator 编排角色发言的作品。👍赞同与？疑惑是每条发言的剧情数值，仅创作者设置，读者不投票；与作品外部社区点赞分开。保留楼层原编号，用回复树、连接线、折叠和父楼层跳转表示关系。编辑界面沿用阅读树，原位编写、选择角色、添加回复和设置计数，可切换最终预览。

校园档案保留摘要，新增最长 50000 字的 Markdown 正文，支持 GFM 表格、标题、列表、粗斜体、引用与代码。工具栏插入语法，编辑/分栏/预览共享同一个安全渲染器。历史按线性版本展示修改说明、编辑者、快照及两版差异；恢复产生新版本，保留乐观锁，不做分支合并。

## 视觉计划与自检（实现前）

对象为校园讨论与可追溯档案；读者快速理解关系，创作者在真实上下文写作。沿用纸白 #ffffff、背景 #f2f4f6、墨蓝 #0a2147、链接蓝 #1d5799、辅助灰 #56657a、节点橙 #c7662e。页面标题用现有宋体/Georgia，正文与控件用现有无衬线，楼层与版本用等宽字体。

论坛采用紧凑单列、头像身份行、正文与反应行；只为真实父子关系绘制回复线。编辑器使用相同节点，元数据收进辅助区；档案分栏编辑在手机上切换单栏，历史为提交列表和差异区域。标志性元素为可折叠回复线与保留原编号的分支。

自检：不照搬 Reddit 黑底，不添加无意义卡片、奖励或分享按钮；缩进编码关系而非装饰。深层回复限制视觉缩进但保留父节点链接，避免手机正文被挤窄。键盘可操作折叠、格式按钮、版本选择；控件有名称、焦点可见，操作反馈可读。

## 数据与交付

追加迁移：forum_messages 两个非负整数计数（上限 999999999，旧数据默认 0），沿用原子草稿 RPC 与发布冻结。Wiki 三张实体表追加 body，创建/修改/恢复均在原修订事务中处理，旧快照缺 body 视为空。无现有业务数据删除。通过 lint/typecheck/build、事务权限/回滚测试和桌面手机真实浏览器检查后，推送 deploy/backend 与 deploy/runtime，通过既有 SSH 更新脚本部署。测试数据仅用于本地隔离环境。

补充需求：包括学生类型的所有论坛身份均可不关联人物档案创建，编辑时可以补充或解除关联；移除旧强制约束，继续保留真实 FK。论坛上下移动保留原有跨越父节点时解除关联并提示的行为。

验证补充：深层树在第 4 级之后停止视觉缩进，继续展示直接父楼层链接；避免 100 层链条压窄手机正文。完整历史 diff 限时 100ms，超时显示精确整段删除/新增。
