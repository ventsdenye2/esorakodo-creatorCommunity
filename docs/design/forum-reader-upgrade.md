# 论坛阅读与共创升级 · 2026-11-16

## 已确认范围

依据《共创网站修改建议.pdf》及本轮用户澄清：桌面右侧真实评论；仅作者 / 受邀协作者 / 所有登录用户三档编辑权限；站内搜索邀请和可撤销链接邀请；手动存档、树形分支、回退后保留后续版本；帖子长图导出；人物图片/立绘；主楼图片入口；按板块阅读下一篇；图片加完整主楼正文的瀑布流（明确不截为摘要）；移动端适配。

作者负责权限、邀请和回退。真实 Creator 评论与虚构 Forum Account 楼层始终分开。保存不等同手动存档；存档保留当时正文，回退必须同时重建协作文档代际，阻止旧页面覆盖。

## 设计简报

对象：空天大学校园论坛；受众：读者与共同写作者；主要任务：从主楼图文发现作品，并连续阅读、讨论或共创。沿用官网已核对的校园主题：纸白 #FBFDFF、浅天蓝 #EDF7FC、正文 #102D46、深海蓝 #123B5A、链接蓝 #1F6697、边界 #CADCE7。宋体用于校园标题，无衬线用于主楼正文与操作。列表用有真实主楼内容的瀑布流；详情为正文与真实评论双栏，窄屏顺序阅读。记忆点是保留完整主楼的校园帖子卡片，图片保持原比例。

评审：用户明确要求小红书式瀑布流，覆盖旧指南“不使用统一卡片瀑布流”的论坛列表限制；不将相同样式扩散到 Wiki/校刊/事件。无图片时保持文字卡片，不补假封面。长正文不截断；栏目与发布时间仍明确。

## 实施状态

已落地代码并完成本地数据库与真实组件隔离复验，尚未部署。迁移、验证与上线状态见 engineering/progress.md 和 verification.md。不得把已有功能、局部测试或本地实现写成生产验收完成。

## 功能细节

- 自动同步持续保存但不创建树节点；编辑者手动存档创建节点并记录作者、时间和版本。原作者可回退，回退前自动存档；旧客户端需刷新。这个语义已向询问 commit 的用户说明。
- 不完整正文状态可以留存，但直接恢复需满足正文和媒体校验；校验失败不会修改公开帖子或当前版本。此批不提供逐人逐次修改的审计 diff。
- 邀请支持站内昵称/账号搜索和 7 天可撤销链接；链接接受操作必须登录并主动确认。仅自己模式暂停其他编辑和链接接受。所有人模式下移除成员不等同拒绝其访问，UI 明示需切换模式。
- 完整主楼首张图片和文字进入列表，桌面三列、手机双列、<360px 单列。图文不人工截断；无图时不添加替代封面。下一篇在相同筛选下按 published_at/id 稳定顺序查找，不受列表 50 条上限限制。
- 长图由 Canvas 绘制正文、发言人、楼层、引用楼层号和图片，不含真实评论；超过单张安全高度按顺序拆分。通过授权媒体同源代理避免跨域污染画布，逐张解码释放，失败不静默丢图。
- 人物图片在编辑档案入口管理，复用 body 中的标准媒体 Markdown；展示时拆出到立绘区。历史引用保留，修改和回退仍受 Wiki 版本事务约束。
- 参考 [luntanti README](https://github.com/congrongpo/luntanti/blob/main/README.md) 的图片楼层与分段长图交互说明；未迁入其本地存储数据模型或复制其源码。
