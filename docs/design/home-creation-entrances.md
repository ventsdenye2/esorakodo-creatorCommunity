# Campus 首页精简与创作入口

## 设计简报

对象为空天大学 Campus 门户；面向来访者与创作者，单一任务是快速开始角色或论坛体创作。2026-10-17已实际查看 https://kongtian.university/ 首屏及官网原始CSS，保留浅天空、海蓝、宋体大标题、校徽、人物群像的原有构图。官网只读，不改动其资源或源码。

色板：纸白#FBFDFF、浅空#EDF7FC、校徽蓝#277EAF、深海#123B5A、正文#102D46、边线#CADCE7。标题沿用Songti SC/STSong/Noto Serif SC，正文Microsoft YaHei/PingFang SC，首页不再添加英文角标或数字编号。布局为左校徽/校名/一句校训/两个大入口，右侧使用官网现有群像；移动端保留群像与按钮的完整性，首屏即可操作。唯一标志元素是官网原画人物从浅色留白中走入画面。

自我批评：以官网真实群像作为首屏主视觉，资讯使用已有堆叠交互，不新增仪表盘、渐变文字或多层小标签。删除首页快讯/关系说明/校刊/校史/Wiki多重栏目；按用户最新要求，在主视觉下方保留单一“校园近况”资讯堆叠，内容仍从顶部原有五个导航进入；顶部与页脚简化为中文品牌和必要导航。创作主入口为“创建角色”和“创作论坛体”，均保持完整可点击的大面积，具备触控、键盘焦点及减少动效支持。

## 验收

比较官网实际首屏与新首页；检查1440/1280桌面、390/320手机布局，两个入口尺寸/URL/可到达、匿名论坛登录保护、校徽/群像加载、键盘顺序/焦点、减少动效、控制台与无框架遮罩。lint/typecheck/build与源码/工程记录同步。首页本身不变更数据库和权限；与已授权的角色创建批次共同上线。

## 实施结果

已实现并完成本地桌面/手机与交互验收；首页资讯以Suspense读取原有真实feed，首屏创作入口不等待资讯；叠层保留前后切换、暂停、键盘焦点/悬停暂停、减少动效，去除英文角标和宣传小字。手机contain保全群像，减少动效下导航只为当前项显示下划线。具体尺寸、命令和调试边界见../engineering/verification.md。本批已随角色创建上线。
