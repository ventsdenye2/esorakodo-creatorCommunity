# 论坛多图与引用 · 2026-10-12

需求：每楼支持多张图片，选择文件与粘贴上传；导入和编辑同步。引用只展示直接目标的身份、楼层、正文、图片缩略图，不递归。楼主按首楼 Forum Account 判断，不按现实 Creator 判断。

视觉计划：校园 BBS 面向读者与创作者，单一任务是按楼层阅读和编排讨论。保留白 #ffffff、墨蓝 #0a2147、链接蓝 #1d5799、灰 #56657a、引用底 #f2f4f6，楼主采用黄 #ffe45c。标题沿用宋体/Georgia，正文沿用无衬线，楼层用等宽字体。单列按楼层排序，引用卡片是辨识元素，内部仅直接目标，图片缩略图可打开原图。自检：取消分支缩进避免手机挤窄，不添加社交平台奖励和装饰。

正文保留 text 列，独立行 ![说明](/api/media/UUID) 表示图片；其他正文按纯文本。共享解析用于导入、保存、编辑预览及阅读。只支持平台已上传图片，不接受本地路径、外部 URL 或 HTML。图片归属与 ready 状态由数据库触发器校验，关联表实现公开作品图片 RLS；原草稿事务及冻结保留。
