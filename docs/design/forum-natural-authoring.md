# 论坛体自然创作

## 页面任务与设计

对象是空天大学戏内校园 BBS，受众是编写整篇论坛体的现实作者，唯一任务是在最终阅读样式里完成讨论。标题 → 首帖 → 连续楼层 → 底部发言框；消息操作按需弹窗，版面、标签、关联档案与 Markdown 导入收进折叠设置。现实作者操作仍有明确按钮，不会变成读者可操作的剧情反应。

沿用官网主题令牌：纸白 #FFFFFF、浅天蓝 #E8F3F8、正文 #123B5A、次级 #4F6A80、边线 #CBD7E6、楼主黄 #FFE45C。标题沿用宋体，正文/操作沿用 Microsoft YaHei/Inter，楼号沿用等宽。单列 920px，移动端 100%-32px；44px 触控目标。唯一显著交互是可点击的真实楼层和按需弹窗，不增加仪表盘卡片或步骤表单。已对照需求批评：取消每层展开字段和预览开关，保留读帖的连续节奏。

## 交互与契约

- /create/forum 无身份也可点击开始，创建空草稿直接进入首帖编辑。标题可在帖子顶部改写，首帖完成前不能增加其他楼层。
- 发言默认自动生成独立 Forum Account（网名、唯一 handle、系统字头像），无需绑定 Student；身份弹窗可选择已有账号或改昵称、上传头像。头像走现有媒体所有权校验。身份资料为跨作品共享资料，修改明确告知会同步该身份其他发言。
- 首楼不可删除、不可在其前插入。设为楼主把目标发言账号改为首楼账号，昵称/头像/标记由同一账号自然派生，不移动楼层。
- 回复追加末尾、只引用目标；向上插楼插入选中消息之前。编辑状态以稳定本地 ID 保存引用，序列化时转换为连续楼号；插楼不能错绑引用。删除目标后清空直接引用并告知影响。
- 底部常驻输入支持连续独立发言、回复上下文和图片；切换目标不丢正文。编辑消息、反应数和身份均按需打开。已有楼层改写自动同步；已发布作品的有效改动实时公开，首次发布由作者操作。未发出的输入阻止保存/发布并给出继续发出或清空的提示。
- 默认账号只在确认发言时创建；独立的身份资料写入可先于草稿保存，失败时保留发言输入。主体改写通过 Yjs 合并与追加迁移 202610170001 的事务提交；协作契约以 forum-collaboration.md 为准，取代此前发布冻结和手动保存约束。
- 原生 dialog 管理焦点、Escape 和键盘圈定；上传/保存过程中禁止关闭或并行写入，错误保留输入，返回触发入口。导入保留原有显式覆盖确认。

## 验收

首帖→独立回复→指定回复→操作弹窗→插楼→引用不变→楼主身份→身份选择/修改→删除影响→保存序列；空账号首帖、100层、错误重试、未发送正文保护；桌面与390px、键盘/触屏、焦点返回、减少动效。静态检查和真实后端保存证据分开记录。
