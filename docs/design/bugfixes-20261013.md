# 2026-10-13 功能测试修复

本批对应网站测试发现的七类缺陷和评论超过 50 条的风险。保留原页面风格、作者归属、Wiki 修订事务和权限规则。

| 编号 | 问题 | 修复契约 |
| --- | --- | --- |
| F1 | Wiki 与论坛身份提交失败会重载并清空输入 | Action 返回结构化错误，在原表单显示；手动 dispatch 保留原生字段和 Markdown；失败、冲突、会话过期均不强制离开编辑页。成功后才跳转。 |
| F2 | 图片上传期间可以保存缺少图片的正文 | ImageUpload 向父表单报告 busy；校刊与补充材料同时禁用保存/发布并在 submit 中拒绝竞态提交。成功插入图片后解锁，失败后保留正文并解锁。身份头像使用相同锁定。 |
| F3 | 编辑后仍显示“已保存” | 对标题、摘要、标签、正文、节点、关联实体和资料性质比较已保存内容；工具按钮与导入同样影响提示。校刊成功保存更新基线，失败不更新。 |
| F4 | 登录忽略 next | 登录表单传递 next，失败保留目的地；服务器只接受本站相对路径，成功返回原创作入口。 |
| F5 | 历史差异的换行导致 React 水合不一致 | 仅显示时把 CRLF/CR 归一化为 LF，pre 内使用 code 保留首个空行；使用确定性的 maxEditLength=1000 上限，超限整段展示。历史快照不改写。 |
| F6 | Auth 直接展示英文供应商错误 | 按供应商 code 映射中文提示，未知错误使用安全中文提示，继续保留 PKCE 和邮件验证。 |
| F7 | RPC 可以发布只有空白段落的文章 | 追加迁移通过表级触发器阻止文章及补充材料发布/清空已发布正文；覆盖 JS trim 的 Unicode 空白，草稿仍可暂存，有效图片和实体引用仍可发布。 |
| R1 | 最早 50 条评论遮蔽后续评论 | 默认读取最新 50 条，按 created_at/id 稳定游标加载更早评论；时间相同不丢失不重复，公开查询仍由原 RLS 授权。 |

数据库迁移 `202610130001_publication_body_guard.sql` 只添加校验函数、触发器和评论索引，无内容回填或删除。部署先迁移后更新 standalone；原运行版本兼容追加 schema，回滚保留校验和索引。

验收以工程 verification 最新条目为准。临时浏览器页面与截图放在仓库外，动作边界使用隔离桩；真实 PostgreSQL 负责业务、事务和 RLS 回归；生产复验单独记录。
