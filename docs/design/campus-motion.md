# 校园站组件动效 · 2026-10-15

## 设计简报

对象是空天大学数字校园，受众为访客、读者与真实 Creator。任务是让访客更自然地发现栏目与记录，保留大学、刊物、档案各自版式。参考官网 https://kongtian.university/ 的实际首屏、js/main.js：标题轻移错峰、栏目顺序入场、入口微抬与缓出。

沿用 Campus White #FBFCFA、Orbital Navy #0A2147、Altitude Blue #296CB7；宋体标题、无衬线操作、等宽索引。沿用左侧标题与右侧纸张卡片、横向快讯、双栏刊物、校史与档案目录。记忆点仍为纸张卡片堆，补充整组轻移缩放入场，不叠加指针视差。批评：不将论坛与校刊改成同款悬浮卡片，不在正文持续漂移，不添加装饰粒子。

## 实现契约

- 首页文案子项间隔 65ms、最多延迟 260ms；普通分区轻移 16px / 520ms，卡片展台 22px / 760ms、缩放 .985 → 1；统一 cubic-bezier(.22, 1, .36, 1)。每个 DOM 节点进入视野时仅播放一次。
- 论坛、校刊、校史事件、校园档案的公开目录标题与记录适度入场；正文阅读、历史对比、编辑器与表单不附加入场效果。
- 导航线从左展开；按钮微抬、箭头前移；目录根据版式使用背景反馈或微抬。位移动效仅在精细指针与支持悬停设备上启用，键盘保留 focus-visible 与箭头反馈。
- 校园视界原生 dialog 与 backdrop 入场；原生 Escape、关闭按钮、焦点返回与栏目选择保持原逻辑。
- 无新增依赖。CampusMotion 为根布局中的无 DOM 客户端增强，现有内容保持 Server Components。IntersectionObserver 只观察 data-motion 和 data-motion-group 的显式目标；MutationObserver 仅监听子节点变化，支持流式与客户端路由，卸载时清理。
- 服务端和 CSS 不隐藏内容；JS 不可用或浏览器不支持时直接显示。使用原生 Web Animations API 的独立 translate/scale，不覆盖卡片 transform。动画结束不保留样式；焦点进入、减少动态效果偏好变化时立即取消。
- 减少动态效果时不注册入场观察器，悬停位移及弹窗动效停用；既有轮播停止自动切换规则保留。恢复滚动到屏幕顶部之外的节点直接显示。

## 验收边界

本批无数据库迁移、内容写入或鉴权变更。需验证桌面、390px、键盘、减少动态效果、客户端导航、目录筛选、轮播与弹窗，执行 lint/typecheck/build。实际结果见 ../engineering/verification.md。本地结果与线上发布状态分别记录。
