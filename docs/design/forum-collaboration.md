# 论坛作品改写与实时协作

## 确认范围

首批当前论坛体。作者发布后可再进入编辑；有效修改自动同步公开阅读页，无再次发布门槛。协作者按现实Creator的@账号添加/移除，只有作者可首次发布与管理成员；Forum Account仍是故事身份。标题、已有楼层正文、身份/数值、引用、插楼/删除、标签和档案关联共同同步。底部未发出的新回复仍是个人输入，发出后加入共享帖子。

输入尚空白、图片未完成等暂时无效状态保留并同步给编辑者，公开页面保持最近有效内容；界面明确指出暂未公开的原因，不丢失改写。

## frontend-design 设计简报

主题是空天大学校园BBS作品，受众是独立与共同创作论坛体的作者，单一任务是在成品样式中自然共写。沿用宋体标题、Microsoft YaHei/Inter正文与等宽楼号。令牌：纸白#FFFFFF、浅蓝#E8F3F8、深海蓝#123B5A、次级#4F6A80、边线#CBD7E6、在线绿#2E8068。布局仍是920px单列，390px换行；44px触控目标，focus/Escape/减少动态效果完备。

标志性元素为帖子抬头下的“共同写作”细条：左侧叠放真实在线头像及人数，右侧同步状态和作者专用成员按钮；成员位置对应正在编辑的楼层。已发布编辑抬头给出清晰的“修改将实时公开”，避免草稿/公开状态混淆。管理弹窗按@账号添加，成员行显示角色和移除；从创作中心和公开帖子均能回到编辑入口，受邀作品有单独入口。

自我批评：不做新的仪表盘、权限表格或高亮大卡片；协作不是新的写作步骤，独立作者仍直接写首帖。在线标记只显示真实会话，断线不伪装成已同步。

## 工程约束

Yjs可合并更新写入私有编辑文档；PostgreSQL乐观序号与行锁保证并发重试，合法快照在同一事务更新现有关系表。SSE带认证检查，每轮检查权限；撤权后停止读写，不依赖频道缓存授权。公开阅读只接收公开版本变更事件并重新读取已发布内容。在线会话有短TTL，退出/失联不永久显示在线。

新增成员/编辑文档/会话/身份池均显式关系与RLS。协作者可使用作品身份和本人身份；不能修改别人管理的全局账号资料。新增图片校验上传者仍在本作品可用范围，不能引用无关作者私有媒体。协作撤销不删除已有贡献、引用或身份。历史迁移不改写，旧版draft RPC不能绕过公开写入入口。无额外WebSocket服务、无service_role浏览器密钥。

源资料：[Yjs更新](https://docs.yjs.dev/api/document-updates)、[相对位置](https://docs.yjs.dev/api/relative-positions)。

根因确认：PostgREST对自定义40001无限事务重试，追加202610170002将应用CAS版本冲突改为P0001，应用自己重新取版并合并。官方说明：https://supabase.com/docs/guides/troubleshooting/high-cpu-and-infinite-transaction-retries-when-using-custom-error-codes-in-rpc-functions-77326b 。前一迁移保持历史不改写。

交付状态：2026-10-17已上线，runtime8175c71；19迁移含40001业务冲突修复。真实双账号14项及匿名5项通过，临时账号/作品已清理。详细证据见../engineering/verification.md。


## 2026-11-13 保存完整性

HTTP保存发送完整Yjs状态（仍按CRDT合并，不整体覆盖并发内容），手动保存即便无排队增量也重传。服务端必须确认pendingStructs与pendingDs均为空才可调用commit_forum_edit；依赖缺失返回409且不变更持久文档。业务字段暂空与CRDT结构不完整分别处理：前者仍可持久暂存，后者拒绝提交。客户端只有确认服务器返回的持久状态包含提交的全部操作（含删除）才清除本地备份；HTTP200自身不构成确认。失败保留备份及待重试状态。单次完整状态仍受2MB上限约束。


## 2026-11-13 手动保存弹窗
主题：空天校园论坛创作；受众：作者与协作者；单一任务：清晰确认手动保存结果。沿用#FFFFFF纸面、#E8F3F8浅空蓝、#123B5A深海蓝、#4F6A80正文及#CBD7E6边线；标题沿用站点宋体，正文沿用现有无衬线。布局为既有520px居中原生dialog，手机左右16px留白。唯一状态标识为保存进度环/成功勾；不引入通知仪表盘或额外装饰。批评：页底细文字不足以确认保存，改为明确的阻塞状态及可恢复失败操作；自动同步不反复弹窗。
手动保存/立即同步显示正在保存，持久确认后显示成功1.5秒自动关闭；失败保留错误、重试、返回编辑及下载备份。发布同样先显示正在发布，成功后再跳转。等待期间禁重复提交/Escape关闭，完成恢复焦点，减少动态效果下停用旋转。旧非协作表单保存也使用同一弹窗。
