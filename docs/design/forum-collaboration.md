# 论坛作品改写与实时协作

## 确认范围

首批当前论坛体。作者发布后可再进入编辑；有效修改自动同步公开阅读页，无再次发布门槛。协作者按现实Creator的@账号添加/移除，只有作者可首次发布与管理成员；Forum Account仍是故事身份。标题、已有楼层正文、身份/数值、引用、插楼/删除、标签和档案关联共同同步。底部未发出的新回复仍是个人输入，发出后加入共享帖子。

输入尚空白、图片未完成等暂时无效状态保留并同步给编辑者，公开页面保持最近有效内容；界面明确指出暂未公开的原因，不丢失改写。

## frontend-design 设计简报

主题是空天大学校园BBS作品，受众是独立与共同创作论坛体的作者，单一任务是在成品样式中自然共写。沿用宋体标题、Microsoft YaHei/Inter正文与等宽楼号。令牌：纸白#FFFFFF、浅蓝#E8F3F8、深海蓝#123B5A、次级#4F6A80、边线#CBD7E6、在线绿#2E8068。布局仍是920px单列，390px换行；44px触控目标，focus/Escape/减少动态效果完备。

标志性元素为帖子抬头下的“共同写作”细条：左侧叠放真实在线头像及人数，右侧同步状态和作者专用成员按钮；成员位置对应正在编辑的楼层。已发布编辑抬头给出清晰的“修改将实时公开”，避免草稿/公开状态混淆。管理弹窗按@账号添加，成员行显示角色和移除；从创作中心和公开帖子均能回到编辑入口，受邀作品有单独入口。

自我批评：不做新的仪表盘、权限表格或高亮大卡片；协作不是新的写作步骤，独立作者仍直接写首帖。在线标记只显示真实会话，断线不伪装成已同步。

## 工程约束

Yjs可合并更新写入私有编辑文档；PostgreSQL乐观序号与行锁保证并发重试，合法快照在同一事务更新现有关系表。SSE带认证检查，每轮检查权限；撤权后停止读写，不依赖频道缓存授权。公开阅读只接收公开版本变更事件并重新读取已发布内容。在线会话有短TTL，退出/失联不永久显示在线。

新增成员/编辑文档/会话/身份池均显式关系与RLS。协作者可使用作品身份和本人身份；不能修改别人管理的全局账号资料。新增图片校验上传者仍在本作品可用范围，不能引用无关作者私有媒体。协作撤销不删除已有贡献、引用或身份。历史迁移不改写，旧版draft RPC不能绕过公开写入入口。无额外WebSocket服务、无service_role浏览器密钥。
