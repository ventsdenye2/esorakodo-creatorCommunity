# 举报审阅

内容管理员需要先看举报对应的实际内容，再决定隐藏、恢复或不予处理。页面单一任务是把举报原因、作品片段与历史处置放在同一条审阅路径中；隐藏作品不通过公开页面旁路展示。

沿用管理区白色纸面、深蓝文字、灰蓝说明框和可见焦点。正文无衬线、标题沿用站内显示字体；只将“处置前 → 处置后”用作审计顺序标记。列表不放即时处置表单，必须进入 `/moderation/[id]` 查阅。细节页包含当前状态、作者display_name、可折叠纯文本片段、举报说明与该举报全部已查询审计说明。手机按单列阅读。没有通用统计仪表盘或装饰性状态图。

`202609240008_moderation_preview.sql` 提供只读 `get_report_preview(p_report_id)`：SECURITY DEFINER、空search_path、先校验auth.uid与moderators成员资格，固定读取报告的四个真实外键之一；不接受表名或任意目标ID。只返回8个白名单字段，excerpt上限12000字，结构化正文仅提取paragraph/heading/quote，论坛按floor_no取前40楼且单楼截断，图片不加载。公开链接仅在work_is_public为真时返回，包括补充父事件状态检查。不改公开RLS，不赋予管理成员授权能力，不给真实账户提升权限。

服务端页面再次核验管理身份；拒绝普通用户，读取异常显示明确重试状态；未成功调阅内容时不显示处置表单。处置方式根据当前published/hidden状态展示，默认不予处理，最终RPC仍负责权限、状态冲突和审计。表单捕获FormData后手动dispatch，出错不清空说明。

验证：新增事务回滚pgTAP覆盖匿名执行权限、普通举报者/作品所有者不可调用、仅管理员读取准确报告目标、草稿/hidden保持RLS隔离、片段长度与字段上限、四种媒介正文、补充父事件hidden公开链接禁止、非法报告ID与撤销成员即时失效。数据库代理实际执行本模块19/19通过，全库7文件187/187通过，所有测试以ROLLBACK结束。

模块 ESLint 与最终类型生成后的全项目 `npm run typecheck` 通过。真实浏览器匿名访问 `/moderation` 显示登录页；无cookie HTTP检查管理列表、不存在的合法报告UUID、非法报告字符串三种路径均先跳转登录，不泄漏任何举报/片段。管理员下不存在报告的行为由回滚pgTAP验证（REPORT_NOT_FOUND），没有为浏览器验收赋予真实账户管理权限，也没有创建新的公开内容。完整管理样式遵循现有portal断点，未将SQL权限测试记作已登录管理员浏览器验收。
