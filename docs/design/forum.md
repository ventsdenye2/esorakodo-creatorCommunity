# 校园论坛公开测试版

## 页面任务

- 对象：一位 Creator 编排多个戏内 Forum Account 发言的论坛作品。
- 受众：浏览校园的访客，以及发布作品的 Creator。
- 单一任务：访客按版面与标签阅读有序楼层；Creator 保存草稿并发布完整作品。

## 结构与视觉

沿用档案纸色、正文墨色、航空蓝链接和少量橙色状态；标题用宋体，操作用无衬线，楼层编号用等宽字。列表用传统 BBS 的横向版面行呈现标题、版面、楼层与发布时间。详情使用一条连续的楼层轴，把账号身份、戏内时间和正文排成可扫描的发言序列。Creator 的草稿编辑工具保持独立区域，避免被误认为角色发言。

移动端压缩列表元数据为两行，楼层身份在正文上方。表单支持增删和上移下移楼层；键盘与触屏使用同一组明确按钮。错误、未登录、空账号、空主题与空版面都提供可执行入口。正文为纯文本，渲染时保留换行，不解释 HTML。

这个阶段没有真实校园地点绑定，论坛不展示假的地点关系。对照通用社区模板的检查点是：编号只代表真实楼层，轴线只连接同一作品中按顺序的发言，版面信息用于筛选而不是装饰。发布后正文冻结，修订和治理留到独立里程碑。

## 交付边界

一个 Creator 可以建立多个 Forum Account，账号可关联公开 Student 档案或保持未知、机构、机器人身份。草稿只对作者可见；公开列表和详情只读取 published。服务端与 RLS 都验证账号所有权。楼层以一次 RPC 替换整个草稿序列，发布由独立事务校验后改变状态。每次改动的实际验证记录在 `docs/engineering/verification.md`。
