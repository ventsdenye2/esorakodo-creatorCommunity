# 创作者操作指南 · 2026-10-01

## 需求与范围

用户反馈创作者不理解创作页，新增公开站内教程 `/guide`，从创作中心、页脚及各编辑入口可达。以当前页面的真实字段和按钮讲解身份、论坛、校园档案、修订、校刊及事件；不新增权限或改变发布流程。论坛反应数仅作者编写，所有论坛身份可独立创建。教程练习仅存在当前浏览器页面，刷新重置，不调用保存接口。

## 实现前视觉计划

对象：首次使用空天大学的共创者。单一任务：跟着具体例子完成第一份作品，并能随时查找操作说明。沿用纸白 #fbfcfa、浅底 #f0f4f2、墨蓝 #0a2147、辅助灰 #536178、链接蓝 #296cb7、节点橙 #c7662e。宋体标题、无衬线操作文案、等宽语法与楼层编号。桌面为窄目录与阅读正文，手机目录自然流动到正文上方，不遮挡控件。

签名元素是“三条发言如何成为回复树”的可操作示例：改变第三层回复对象，立刻看到真实 ThreadTree 的层级变化；另提供与档案编辑页相同的 Markdown 练习。比较过纯 FAQ 和强制浮层引导：操作手册便于回查，练习解释关系更直接。避免介绍页式卡片堆叠、装饰性步骤编号和虚构功能。顺序编号仅用于真正操作步骤。

编辑器旁的教程链接在新标签页打开并明确标注，保留未保存输入。页面公开可读；练习不要求登录，不产生数据库数据。无加载型数据，不需要额外空态；权限、保存失败、冲突、无身份和论坛发布冻结在教程中明确说明。语义目录、可见焦点、移动端换行、原生 details、无新增动画。

## 验证与交付计划

对照当前表单和 actions 校对文案；lint/typecheck/build；真实浏览器检查目录、回复示例、Markdown 工具栏、手机布局与新标签页链接。沿用已授权源码推送及 SSH runtime 更新流程；无数据库迁移。

## 用户补充后的图解方案

用户要求必须直观：原页面截图配合文案对应关系，不能只有文字。主内容改为原界面截图 + 橙色编号/框选 + 同编号说明，练习收进可展开区域。截图来自现有页面/组件实际浏览器渲染，使用演示内容，不是重新绘制的界面。身份、论坛创建/编辑和 Wiki 创建调用原 page；历史、校刊和事件调用原编辑组件。隔离截图环境仅替换数据读取、保存边界及截图外的导航壳，不改动表单 DOM 或样式；禁止保存，未读取真实私人草稿。截图按操作区域裁切，使用完整桌面渲染高度避免底部固定操作条遮挡正文。

截图保存在 public/guide，编号位置按实际元素边界转为百分比，随图片缩放；每张图可在新标签页打开原图。文字提供完整操作含义，图片无法加载时仍可读。手机图下说明单列，图像不超出屏幕。截图日期为 2026-10-01；界面变动需同时更新截图与编号位置。
