# 创作 Markdown 导入

面向已经在本地完成作品的创作者：下载模板或让 AI 按模板整理，选择文件后填入现有编辑器，再预览、保存、发布。沿用纸色背景、细分隔线、正文排版和现有按钮；入口使用可展开的导入工作区，避免独立工具仪表盘。移动端纵向排列，原生文件选择和按钮支持键盘，状态使用 live region，不添加动画。

三个版本化格式分别对应论坛、校刊与事件。文件最多 512 KiB，UTF-8，头部为严格的单行 key: value 元数据（不是通用 YAML）。明确拒绝未知字段、重复字段、无效顺序和超出领域限制的数据。格式错误不改变编辑器。导入覆盖前明确勾选确认；已有关联保留。

论坛导入重新校验服务器文本，复用当前作者账号，一次批量原子插入缺少的独立身份；不修改已有身份或归属，账号冲突时不填入正文。创建身份与保存作品是不同操作。事件仅新建或草稿支持整体导入，避免破坏公开节点引用。无数据库迁移。

解析器、模板、三个编辑器及图解教程已实现。lint/typecheck/Windows build、26 项格式回归与 41 项数据库检查通过；真实组件桌面/手机文件导入与错误保留检查通过。服务器身份创建由现有 RLS 与批量 INSERT 的原子性保护；浏览器演示夹具不作为生产写入验收。Linux 发布构建与启动检查通过，runtime `4bef03f` 已上线并核对公开教程、模板和截图。
