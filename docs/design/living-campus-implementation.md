# Living Campus v2 前端实施记录

> 2026-09-23 工作批次；本文记录实际改动与未完成边界。工程进度与全站验收由 `docs/engineering/progress.md`、`verification.md` 汇总。

## 本批设计简报

- **对象 / 受众 / 单一任务**：虚构的空天大学共创校园；面向初次访问的读者与潜在 Creator；首页首先帮助用户从可用的档案或论坛入口开始探索。
- **颜色**：纸面 `#fbfcfa`、档案灰绿 `#f0f4f2`、文字深蓝 `#0a2147`、航空蓝 `#296cb7`、提示橙 `#c7662e`、沙盘地面 `#eaf0ed`。具体 CSS 令牌以 `app/globals.css` 为准。
- **字形**：世界观标题沿用宋体，操作与正文沿用现有无衬线，坐标标签与资料元信息用现有等宽字体。不加载新远程字体。
- **版面**：收紧页头；桌面 Hero 左文右沙盘，随后为真实内容空状态和下移的关系概念区；手机 Hero 后只保留轻量概念海报，完整校园视界由页头打开。
- **唯一标志**：正交感建筑群组成的概念沙盘，在弹层中成为可选择的三处探索入口。沙盘有明确演示标识，既展现未来空间方向，也不声称建筑、位置或关系已写入 Canon。

设计复核：没有采用霓虹 HUD、通用卡片瀑布或凭空生成实时统计。点位 A/B/C 只分别进入现有 `/wiki`、`/forum`、`/press` 路由；它们不是已确认 Place 或数据库关系。

## 实际改动

- `CampusHero` 将原轨道图移出首屏，保留档案与注册的真实入口；概念沙盘为轻量内联 SVG，首页无 Three.js 或完整 3D 模型下载。
- 全站页头增加“校园视界”触发按钮。原生 dialog 支持 Esc、点击遮罩、关闭后焦点返回，打开后焦点进入关闭按钮。点位按钮与侧边/下方列表提供键盘和触屏的同一条 2D 探索路径。
- 首页原“校园动态”的虚构更新改为诚实空状态。关系图、论坛/校刊样例及事件时间线现在标明“概念演示”；它们仍是静态编辑示意，尚未连接真实发布数据。
- 移动端将场景和信息 sheet 纵向排列；全局 reduced-motion 规则也覆盖该弹层。原有五个主路由保留，登录可直接进入。

## 待续与验收边界

- 本批没有改变 Wiki/Auth/Forum 数据、RLS、迁移或正式 3D 资产。真实校园 Place 到模型 objectName/锚点仍需独立契约与批准后的设定。
- `CampusTrace` 的名字/连线和首页论坛、校刊、事件样例都是概念演示，不应作为已发布内容展示；后续可在真实记录查询完成后替换为数据驱动的关系与动态。
- 本地 `npm run lint` 已通过。桌面 1280×720 与手机 390×844、375×812 的 Playwright 渲染截图已逐一检查：首屏有下段内容、按钮及点位可读、页面无横向溢出。浏览器打开弹层后关闭按钮获得焦点；Esc 关闭后焦点返回“校园视界”触发按钮；手机上选择论坛点位后信息 sheet 更新为“打开校园论坛”。
- 首轮 typecheck 因并行 M3 新论坛表尚未进入生成类型而失败，主集成任务已在类型再生成后验证通过。此批单独完成前不要把静态草稿当成数据库已发布内容；全仓 build 与论坛联调结果由主集成任务记录。
